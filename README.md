# Project 1 : ##ASIA CUP (1984–2023): THE CONTINENTAL LEDGER
##Data
The dataset comprises historical match records, individual player performance statistics, dismissal logs, and venue metrics across all official ODI andT20I Asia Cup tournaments
held between 1984 and 2022.
##Objective -
To engineer an enterprise-grade Power BI dashboard that converts 38 years of historical tournament data into a structured digital ledger.
The project focuses on tracking match variables, venue behavioral patterns, and player micro-metrics to deliver data-driven insights into subcontinental cricket dominance.
##Description-
This data analytics project performs a comprehensive historical audit of Asia Cup cricket data across its entire lifecycle from 1984 to 2022. 
By ingesting, cleansing, and modeling multi-era match records, the solution translates raw performance statistics into high-value visual intelligence.
It utilizes dynamic DAX expressions, strategic dimension slicing, and intentional page clustering to map scoring velocities, tracking trends, and head-to-head competitive rivalries. Ultimately, the dashboard eliminates data noise to pinpoint the precise statistical differentiators that drive match outcomes and tournament championships.
##Tools
• Power BI Desktop: Utilised as the primary visualization engine to handle multi-page storytelling, create smooth bookmark-driven user journeys,
and render complex visualizations like gauges and custom matrices.
• Power Query: Critical for the initial Extract, Transform, Load (ETL) phase to clean inconsistencies across 38 years of historical data,
format missing fields, and standardize naming conventions across evolving eras.
• DAX (Data Analysis Expressions): Crucial for engineering custom dynamic measures (such as historical win tracking and multi-format scoring velocity metrics) that
update instantly based on user-selected slicers.
